VisioFex/KonaCash API

WooCommerce Payment Gateway Integration

🔐 Authentication: All API requests require the X-API-KEY header with your secret key from the VisioFex portal.
⚙️ Configuration: The vendor field requires your App ID from the VisioFex portal (found under Developer → New App).
POST

Create Checkout Session

/checkout/sessions/create
Creates a new hosted checkout session for payment processing. The session includes order details, URLs for success/return/cancel flows, and metadata for tracking.
Request
Response

Request Body (application/json)

vendor string required
Vendor/App ID from VisioFex portal (found under Developer → New App)
env string required
Environment: "test" or "live"
currency string required
Three-letter currency code (lowercase)
amount string required
Total order amount (formatted to 2 decimal places)
successURL string required
URL to redirect after successful payment
returnURL string required
URL for "back to store" button (checkout page)
cancelURL string required
URL for cancelled payments
lineItems array
Array of order line items (products, shipping, fees, etc.)
metadata object
Additional order metadata for tracking
{ "vendor": "your-app-id", "env": "live", "currency": "usd", "amount": "99.99", "successURL": "https://store.com/checkout/order-received/123/", "returnURL": "https://store.com/checkout/", "cancelURL": "https://store.com/checkout/order-received/123/?cancel_order=true", "lineItems": [ { "name": "Premium Widget", "quantity": 2, "unitPrice": "49.99", "totalPrice": "99.98", "sku": "WIDGET-001", "type": "product" } ], "metadata": { "order_id": "123", "site_url": "https://store.com", "wc_total": 99.99, "coupon_count": 1, "has_shipping": true } }
200 Success
{ "data": { "session": { "_id": "sess_1234567890abcdef", "status": "active" }, "paymentURL": "https://checkout.konacash.com/pay/sess_1234567890abcdef", "requestID": "req_abcdef1234567890" } }

POST

Process Refund

/transactions/{paymentId}/refund
Processes a refund for a completed transaction. Refunds can be partial or full amounts.
Request
Response

Path Parameters

paymentId string required
The payment/transaction ID to refund

Request Body (application/json)

payment_id string required
Payment ID (same as URL parameter)
amount string required
Refund amount (formatted to 2 decimal places)
reason string required
Reason for the refund (must be one of: requested_by_customer, duplicate, fraudulent)
{ "payment_id": "txn_1234567890abcdef", "amount": "25.00", "reason": "requested_by_customer" }
200 Success
{ "data": { "_id": "ref_1234567890abcdef", "transactionId": "txn_1234567890abcdef", "amount": "25.00", "currency": "usd", "reason": "requested_by_customer", "status": "succeeded", "createdAt": "2025-09-23T14:30:00Z", "processedAt": "2025-09-23T14:31:00Z" } }
400 Bad Request
{ "error": "Invalid refund amount" }
