# VisioFex API Documentation

This directory contains comprehensive API documentation for the VisioFex/KonaCash payment gateway integration with WooCommerce.

## Files

- **`visiofex-api-specification.yaml`** - OpenAPI 3.0 specification in YAML format
- **`api-docs.html`** - **Interactive API documentation viewer (open in browser - works locally!)**

## How to View the Documentation

### Option 1: Interactive Browser View (Recommended - Works Locally!)
1. **Simply double-click `api-docs.html`** in your file explorer
2. No web server required - works directly from your local filesystem
3. Features full interactive documentation with expandable endpoints, request/response schemas, and code examples

### Option 2: View YAML Specification
1. Open `visiofex-api-specification.yaml` in any text editor
2. Or use an online OpenAPI viewer like:
   - [Swagger Editor](https://editor.swagger.io/)
   - [SwaggerHub](https://swaggerhub.com/)
   - [Stoplight](https://stoplight.io/)

## API Endpoints Documented

### Core Payment Flow
- **POST** `/checkout/sessions/create` - Create hosted checkout session
- **GET** `/checkout/sessions/{sessionId}` - Get session details

### Transaction Management
- **GET** `/transactions?sessionId={sessionId}` - Get transactions by session
- **GET** `/transactions/{transactionId}` - Get transaction details

### Refund Management
- **GET** `/refunds?transactionId={transactionId}` - Get refunds by transaction
- **POST** `/transactions/{paymentId}/refund` - Process a refund (with predefined reasons: requested_by_customer, duplicate, fraudulent)

## Authentication

All API requests require the `X-API-KEY` header with your secret key from the VisioFex portal.

## Configuration Required

Before using the API, you must configure your VisioFex credentials in the WooCommerce plugin:

### **Required Settings:**
- **Secret Key**: Your API key from the VisioFex portal (used in `X-API-KEY` header)
- **Vendor ID**: Your App ID from the VisioFex portal (required for checkout session creation)
- **Store Domain**: Your website URL (auto-detected but can be overridden)

### **Getting Your Credentials:**
1. Log into the [VisioFex portal](https://visiofex.com/login)
2. Navigate to **Developer** → **New App**
3. Copy your **App ID** (this is your Vendor ID)
4. Go to **API Keys** and copy your **production API key** (this is your Secret Key)

### **WooCommerce Configuration:**
In WordPress admin → **WooCommerce** → **Settings** → **Payments** → **VisioFex Pay**:
- Enter your **Secret Key** in the "Secret Key" field
- Enter your **App ID** in the "Vendor ID" field
- The Store Domain is auto-detected (leave blank unless you need to override)

## Refund Reasons

When processing refunds, the `reason` field must be one of these predefined values:
- `requested_by_customer` - Customer requested the refund
- `duplicate` - Duplicate transaction
- `fraudulent` - Fraudulent transaction

## Base URL
